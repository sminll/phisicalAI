# PRD: AI 분리수거 도우미 스마트 쓰레기통

> 카메라와 AI를 이용하여 사용자가 버리려는 쓰레기의 종류를 인식하고,
> 올바른 분리수거 위치를 안내하는 스마트 쓰레기통을 제작한다.

- 작성자: 이수민
- 작성일: 2026-10-06
- 버전: v0.2 (v0.1 대비 문제 정의·시나리오·KPI·기술 스택·범위·ROI 보완)
- 프로젝트 유형: 피지컬 AI 프로토타입 (학교/공공장소 시범 설치용)

---

## 1. 문제 정의

### 1.1 배경

공공장소나 학교에서 페트병, 캔, 일반쓰레기 등이
올바르게 분리되지 않고 잘못 버려지는 경우가 많다.
분리배출함이 있어도 사용자가 쓰레기의 종류와 배출 기준을 **직접 판단**해야 하기 때문에,
기준을 잘 모르거나 급한 상황에서는 아무 칸에나 버리게 된다.

### 1.2 핵심 문제

| 구분 | 문제 | 결과 |
|---|---|---|
| 사용자 | 분리배출 기준을 모르거나 헷갈림 (예: 라벨 붙은 페트병, 종이컵, 은박 포장재) | 잘못된 칸에 투입 |
| 사용자 | 판단에 시간이 걸리고 귀찮음 | "일단 일반쓰레기"로 버리는 습관 |
| 관리자 | 오염·혼입된 재활용품을 다시 선별해야 함 | 선별 인력·시간 증가 |
| 환경 | 혼입된 재활용품은 재활용되지 못하고 소각·매립 | 재활용률 저하 |

### 1.3 문제 가설

> "쓰레기를 버리는 **그 순간**에 무엇을 어디에 버려야 하는지 즉시 알려주면,
> 사용자는 별도의 학습 없이도 올바르게 분리배출할 것이다."

### 1.4 해결 방향

카메라와 경량 AI 모델을 이용해 쓰레기의 종류를 자동으로 인식하고,
LED와 자동 뚜껑으로 올바른 투입구를 **직관적으로** 안내하는 시스템을 제작한다.
사용자는 버튼 조작 없이 쓰레기를 카메라 앞에 보여주기만 하면 된다.

## 2. 사용자 시나리오

### 2.1 대상 사용자 (페르소나)

| 페르소나 | 특징 | 니즈 |
|---|---|---|
| 학생 (주 사용자) | 쉬는 시간에 급하게 음료 용기를 버림, 분리배출 기준에 관심 낮음 | 빠르고 생각할 필요 없는 안내 |
| 방문객 / 외국인 | 국내 분리배출 기준을 잘 모름, 한글 안내문 이해 어려움 | 언어에 의존하지 않는 시각적 안내 (색·불빛) |
| 시설 관리자 | 쓰레기통 관리 및 재선별 담당 | 혼입률 감소, 투입 통계 확인 |

### 2.2 기본 시나리오 (Happy Path)

1. 사용자가 쓰레기통 앞에 다가와 버릴 쓰레기를 카메라 앞(인식 영역)에 가져간다.
2. 근접 센서(또는 영상 변화 감지)가 물체를 감지하면 카메라가 이미지를 촬영한다.
3. AI 모델이 이미지를 분석해 쓰레기 종류와 신뢰도(confidence)를 산출한다.
4. 시스템이 **페트병 / 캔 / 일반쓰레기** 중 하나로 분류를 결정한다.
5. 해당 투입구의 LED가 켜지고 서보모터로 뚜껑이 자동으로 열린다. (디스플레이에 결과 표시)
6. 사용자가 안내에 따라 쓰레기를 버린다.
7. 일정 시간(약 5초) 후 뚜껑이 닫히고 대기 상태로 돌아간다. 분류 결과는 로그(이미지 제외)로 기록된다.

### 2.3 예외 시나리오

| 상황 | 시스템 동작 |
|---|---|
| 신뢰도가 기준(예: 0.7) 미만 | 노란색 LED 점멸 + "다시 보여주세요" 안내, 최대 2회 재시도 |
| 2회 재시도 후에도 판별 실패 | 일반쓰레기 투입구를 안내 (안전한 기본값) |
| 여러 물체가 동시에 인식됨 | "하나씩 보여주세요" 안내 후 재촬영 |
| 카메라 앞에 사람 얼굴만 보임 | 분류하지 않음, 영상 저장하지 않음 |
| 모터 동작 실패 / 걸림 | LED 안내만 수행, 오류 로그 기록 |

### 2.4 사용자 흐름 요약

```
대기 → 물체 감지 → 촬영 → AI 추론 → (신뢰도 ≥ 기준?) ─ 예 → LED/뚜껑 안내 → 투입 → 대기
                                         └ 아니오 → 재시도 안내 (최대 2회) → 일반쓰레기 안내
```

## 3. 성공 지표 (KPI)

### 3.1 핵심 KPI

| 구분 | 항목 | 목표 | 측정 방법 |
|---|---|---|---|
| 정확도 | 쓰레기 분류 정확도 | **90% 이상** | 클래스별 30개 이상, 총 100개 이상 테스트 샘플로 정답률 측정 |
| 정확도 | 클래스별 최저 정확도 | 85% 이상 | 페트병·캔·일반쓰레기 각각의 정확도 중 최솟값 |
| 속도 | 인식 속도 (물체 제시 → 안내) | **2초 이내** | 촬영~LED 점등까지 시간 로그, 평균 및 95백분위 측정 |
| 범위 | 분류 대상 | 페트병, 캔, 일반쓰레기 **3종 이상** | 지원 클래스 수 |
| 신뢰성 | 장치 동작 성공률 | **95% 이상** | LED·서보 동작 100회 반복 시험 중 정상 동작 비율 |
| 사용성 | 사용자 조작 | 별도 버튼 조작 **0회** | 사용 테스트 관찰 |

### 3.2 효과 KPI (시범 운영 시 측정)

| 항목 | 목표 | 측정 방법 |
|---|---|---|
| 잘못된 분리배출(혼입) 비율 | 설치 전 대비 **50% 이상 감소** | 설치 전/후 1주일간 투입물 샘플 검사 |
| 사용자 만족도 | 5점 만점 중 4점 이상 | 사용자 10명 이상 설문 |
| 첫 사용 성공률 | 80% 이상 | 설명 없이 처음 사용한 사용자가 올바르게 버린 비율 |

## 4. 기술 스택

### 4.1 시스템 구성

```
[USB 카메라] → [Raspberry Pi: Python + AI 추론] → (시리얼 통신) → [Arduino] → [LED / 서보모터]
                         └→ [디스플레이(선택): 결과 표시]
```

### 4.2 상세 스택

| 영역 | 선택 | 선정 이유 / 비고 |
|---|---|---|
| 카메라 | USB 웹캠 (720p) | 저렴하고 Raspberry Pi와 호환 용이 |
| 메인 컴퓨터 | Raspberry Pi 4 (4GB) | 온디바이스 AI 추론 가능, 오프라인 동작 |
| 제어 보드 | Arduino Uno | LED·서보모터 제어 안정성, 메인 연산과 분리 |
| AI 모델 | YOLOv8n 또는 MobileNetV3 기반 이미지 분류 | 경량 모델로 저사양 장치에서 2초 이내 추론 |
| 추론 런타임 | TensorFlow Lite 또는 ONNX Runtime | Raspberry Pi에서의 추론 속도 최적화 |
| 학습 환경 | Google Colab (GPU) | 무료 GPU로 전이학습(Transfer Learning) |
| 데이터셋 | 직접 촬영 이미지 + 공개 쓰레기 이미지 데이터셋 | 실제 설치 환경(조명·배경)과 유사한 데이터 확보 |
| 개발 언어 | Python (AI·제어 로직), C++ (Arduino 펌웨어) | |
| 주요 라이브러리 | OpenCV, Ultralytics/TFLite, pyserial | 영상 처리, 추론, 시리얼 통신 |
| 출력 장치 | RGB LED 3개, SG90 서보모터 3개 | 투입구별 안내 및 뚜껑 개폐 |
| 센서 (선택) | 초음파 센서 HC-SR04 | 물체 접근 감지로 불필요한 추론 방지 |
| 개발 환경 | VS Code, Arduino IDE | |

## 5. 범위 / 비범위

### 5.1 범위 (In Scope)

| 기능 | 설명 | 우선순위 |
|---|---|---|
| 이미지 촬영 | 물체 감지 시 카메라로 쓰레기 이미지 촬영 | P0 |
| AI 판별 | 페트병·캔·일반쓰레기 3종 분류 및 신뢰도 산출 | P0 |
| 결과 안내 | 해당 투입구 LED 점등 | P0 |
| 장치 제어 | 서보모터로 해당 투입구 뚜껑 자동 개폐 | P1 |
| 예외 처리 | 낮은 신뢰도 시 재시도 안내, 실패 시 일반쓰레기 안내 | P1 |
| 결과 표시 | 디스플레이 또는 PC 화면에 분류 결과 표시 | P2 |
| 로그 기록 | 시간·분류 결과·신뢰도 기록 (이미지 제외) | P2 |

### 5.2 비범위 (Out of Scope)

| 항목 | 제외 이유 |
|---|---|
| 음식물·이물질 오염 여부 판단 | 추가 센서와 대규모 데이터가 필요해 프로토타입 범위 초과 |
| 모든 종류의 쓰레기 분류 (종이, 비닐, 유리 등) | 1차 버전은 3종으로 정확도 확보에 집중, 추후 확장 |
| 실제 대형 쓰레기통 제작 | 소형 모형(박스 기반)으로 동작 검증 |
| 공공 분리수거 시설·서버와의 연동 | 네트워크·보안 요구사항이 커서 제외 |
| 쓰레기 자동 분류 투입 (컨베이어 등) | 안내형 시스템으로 한정, 투입은 사용자가 직접 수행 |
| 사용자 인식 / 개인별 기록 | 프라이버시 보호를 위해 제외 |

### 5.3 향후 확장 (Future)

- 종이·비닐·유리 등 분류 클래스 확장
- 적재량 감지 센서로 수거 시점 알림
- 투입 통계 대시보드 (관리자용)

## 6. ROI 및 제약조건

### 6.1 예상 비용 (프로토타입 1대 기준)

| 항목 | 예상 비용 |
|---|---|
| Raspberry Pi 4 (4GB) + 전원 + SD카드 | 약 60,000원 |
| USB 웹캠 | 약 15,000원 |
| Arduino Uno (호환 보드) | 약 8,000원 |
| SG90 서보모터 3개 | 약 6,000원 |
| RGB LED, 저항, 점퍼선, 브레드보드 | 약 5,000원 |
| 초음파 센서, 외함(박스) 재료 | 약 6,000원 |
| **합계** | **약 100,000원 이내** |

> 학교에 기존 Raspberry Pi/Arduino 키트가 있으면 비용은 약 3~4만 원 수준으로 줄어든다.

### 6.2 기대 효과 (ROI)

| 구분 | 기대 효과 |
|---|---|
| 환경 | 혼입률 감소로 재활용 가능한 페트병·캔이 실제 재활용될 비율 증가 |
| 운영 | 관리자의 재선별 작업 시간 감소 (혼입률 50% 감소 시 재선별 시간도 비례 감소 기대) |
| 교육 | 버릴 때마다 올바른 분류를 보여줘 사용자의 분리배출 습관 형성 |
| 확장성 | 저비용(10만 원 이내)·오프라인 구조로 여러 장소에 복제 설치 용이 |
| 학습 | 데이터 수집 → 모델 학습 → 임베디드 배포 → 하드웨어 제어까지 피지컬 AI 전 과정 경험 |

### 6.3 제약조건

| 항목 | 내용 |
|---|---|
| 속도 | 물체를 카메라에 보여준 후 2초 이내에 결과가 나와야 함 |
| 비용 | 프로토타입 1대 기준 약 10만 원 이내 |
| 오프라인 | 인터넷 연결 없이 모든 AI 인식이 장치 내부에서 동작 |
| 프라이버시 | 사람의 얼굴이 촬영될 수 있으므로 영상·이미지를 저장하지 않음 (결과 텍스트 로그만 저장) |
| 모델 크기 | Raspberry Pi에서 실행 가능한 경량 모델 (모델 파일 약 10MB 이하 목표) |
| 환경 | 실내 조명 기준으로 동작, 역광·어두운 환경은 성능 저하 가능 |
