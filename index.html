01 · 문제 정의

분리수거함은 있는데, 왜 잘못 버려질까요?

사용자가 쓰레기 종류와 배출 기준을 직접 판단해야 하기 때문입니다. 기준을 모르거나 급할 때는 아무 칸에나 버리게 되고, 그 부담은 관리자와 환경으로 이어집니다.

사용자

기준을 모름

라벨 붙은 페트병, 종이컵, 은박 포장재처럼 헷갈리는 쓰레기가 많아 잘못된 칸에 투입합니다.

사용자

판단이 귀찮음

쉬는 시간처럼 바쁜 순간에는 고민할 여유가 없어 "일단 일반쓰레기"로 버리는 습관이 생깁니다.

관리자

재선별 부담

혼입된 재활용품을 다시 골라내야 해서 선별 인력과 시간이 계속 늘어납니다.

환경

재활용률 저하

잘못 섞인 페트병과 캔은 재활용되지 못하고 소각·매립되어 자원이 낭비됩니다.

문제 가설

쓰레기를 버리는 그 순간에 무엇을 어디에 버려야 하는지 즉시 알려주면, 사용자는 별도의 학습 없이도 올바르게 분리배출할 것이다.

02 · 작동 방식

보여주기만 하면, 2초 안에 안내합니다

물체 감지부터 투입까지, 사용자는 아무 버튼도 누르지 않습니다.

  1. 1

    물체 감지

    근접 센서가 카메라 앞의 쓰레기를 감지합니다.

  2. 2

    촬영

    USB 카메라가 쓰레기 이미지를 촬영합니다.

  3. 3

    AI 추론

    경량 모델이 종류와 신뢰도를 산출합니다.

  4. 4

    LED · 뚜껑 안내

    올바른 투입구의 LED가 켜지고 뚜껑이 열립니다.

  5. 5

    투입 완료

    5초 후 뚜껑이 닫히고 대기 상태로 돌아갑니다.

시스템 구성

INPUT USB 카메라 720p 웹캠 · 초음파 센서
AI · PYTHON Raspberry Pi 4 MobileNetV3-Small · TFLite INT8
CONTROL · SERIAL Arduino Uno LED · 서보 제어 펌웨어
OUTPUT LED · 서보모터 RGB LED 3 · SG90 3

예외 처리 신뢰도 0.7 미만이면 노란 LED로 재시도를 안내하고, 2회 실패 시 일반쓰레기 투입구를 안내합니다.

03 · 데이터 처리

AI가 보기 전에 다듬고, 본 뒤에 한 번 더 확인합니다

설치 후보 장소(본관 2층 매점 옆 창가)를 현장 조사해 보니 오후 역광, 늘 함께 찍히는 손, 부족한 캔 데이터가 정확도를 위협했습니다. 그래서 사진을 모델에 넣기 전의 전처리 11단계와, 모델의 답을 그대로 믿지 않는 후처리 판단 규칙을 설계했습니다.

학습 학습할 때만 공통 학습과 실시간 추론에 같은 코드로 적용

    후처리: 모델의 답을 바로 믿지 않습니다

    추론이 끝나면 판단 규칙을 위에서부터 차례로 확인합니다. 걸리는 항목이 있으면 노란 LED로 다시 보여달라고 안내하고, 최대 2번까지 다시 찍습니다.

    실시간 처리 순서

    1. 초음파 센서가 물체 접근을 감지
    2. 카메라에 남은 오래된 프레임 3장을 버림
    3. 5장을 연속 촬영해 가장 선명한 1장만 선택
    4. 공통 전처리(6·7·8·11) 후 INT8 모델로 추론
    5. 원본 사진은 즉시 메모리에서 삭제
    6. 판단 규칙 적용 후 결과만 텍스트로 기록
    1. 1
      '물체 없음'으로 나왔나요?

      지나가는 사람에게 센서가 반응한 경우입니다. 다시 찍고, 3번 모두 비어 있으면 뚜껑을 열지 않습니다.

      취소
    2. 2
      흔들려서 흐린가요?

      쓰레기를 던지듯 보여주면 선명도가 기준 미만으로 떨어집니다. 흐린 사진의 답은 쓰지 않습니다.

      다시 보여주세요
    3. 3
      신뢰도가 0.7보다 낮은가요?

      플라스틱 컵, 은박 봉지처럼 헷갈리는 물체에서 자주 생깁니다. 확신이 없으면 다시 확인합니다.

      다시 보여주세요
    4. ✓
      모두 통과

      판별한 투입구의 LED가 켜지고 뚜껑이 열립니다.

      투입구 안내
    5. !
      2번 다시 찍어도 판별 실패

      재활용 칸이 오염되지 않도록 일반쓰레기 투입구를 안내합니다. 잘못 섞이는 쪽보다 안전한 선택입니다.

    04 · 주요 기능

    작고 저렴하지만, 필요한 건 다 합니다

    AI 3종 분류

    페트병 · 캔 · 일반쓰레기를 신뢰도와 함께 판별합니다.

    PETCANGENERAL

    자동 뚜껑 개폐

    서보모터가 해당 투입구의 뚜껑만 열고, 5초 후 자동으로 닫습니다.

    LED 색상 안내

    언어 없이도 이해되는 불빛 안내로 외국인 방문객도 쉽게 사용합니다.

    재시도 · 예외 처리

    낮은 신뢰도, 여러 물체 동시 인식 등 예외 상황에서도 안전하게 동작합니다.

    오프라인 온디바이스 AI

    인터넷 없이 Raspberry Pi에서 직접 추론합니다. 10MB 이하 경량 모델.

    프라이버시 보호

    영상과 이미지는 저장하지 않고, 분류 결과 텍스트 로그만 기록합니다.
